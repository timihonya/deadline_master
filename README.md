Устанавливать рабочую версию нужно из ветки httpx-and-SQLite.
Откройте файл .env, вставьте токен и раскомментируйте строку.

Запуск в Docker Desktop:
1. Открыть терминал в папке проекта (cd /путь_к_папке);
2. Прописать команду "docker compose up --build --pull always";
3. Бот запущен! (для того чтобы остановить работу бота нажмите сочетание клавиш Ctrl + C в том же терминале).

Запуск в консоли:
1. Открыть терминал в папке проекта (cd /путь_к_папке);
2. Установить зависимости, указанные в requirements.txt (pip install -r requirements.txt);
3. Запустить бота через команду "python main.py".

Цель проекта:  
Создать удобный инструмент, который поможет школьникам ответственнее относиться к учёбе, самостоятельно планировать время и не забывать о важных заданиях.  
Мы стремимся сделать выполнение учебных задач не только организованным, но и мотивирующим.  
Дедлайн-хранитель - успевай больше, забывай меньше!

Основные компоненты проекта:  
main.py - основная логика бота и обработка пользовательских действий.  
api_client.py - взаимодействие с MAX Bot API.  
keyboards.py - создание клавиатур и кнопок.  
requirements.txt - список необходимых Python-библиотек.  
Dockerfile - инструкции для сборки Docker-образа.  
generated/ - директория для файлов и баз данных приложения.  
profile_images/ - директория, в которой хранятся аватары для профиля.  

Основные возможности:  
Управление заданиями - добавление учебных задач с указанием названия, типа и срока выполнения.  
Список заданий - просмотр добавленных задач и контроль их выполнения.  
Контроль нагрузки - оценка текущей учебной загруженности.  
Напоминания - уведомления о приближающихся сроках выполнения заданий.  
Игровой профиль - отображение уровня, опыта, монет, серии активности и количества выполненных заданий.  
Магазин аватарок - возможность приобретать и устанавливать аватарки за внутриигровую валюту.  
Система уровней - получение опыта и открытие новых предметов по мере выполнения заданий.  
Изменение имени профиля - возможность настроить отображаемое имя.  

Используемые инструменты:  
Python - основной язык программирования.  
SQLite - хранение пользовательских данных, заданий и информации о магазине.  
Pillow - создание графических карточек профиля.  
Pilmoji - отображение эмодзи на изображениях.  
Docker - контейнеризация приложения.  
MAX Bot API - взаимодействие с платформой MAX.
